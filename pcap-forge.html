▸ PLANNED FEATURES // DETECTION ENGINEERING TOOLKIT ROADMAP
Features are listed in approximate implementation priority. Contributions and feedback welcome.
SHIPPED v2.3
PCAP IMPORT & PARSE
Drag in an existing .pcap file and display it in the same packet summary view. Quick triage without Wireshark. Parse frame headers, extract protocol fields, and display alongside generated captures.
SHIPPED v2.3
SURICATA / SNORT RULE STUB
Generate a draft .rules file alongside the Sigma rule. Correct protocol keyword, content matches, pcre where appropriate, and metadata fields pre-filled from the parsed session.
SHIPPED v2.3
YARA RULE STUB
For sessions with injected file payloads, generate a YARA rule targeting the file's magic bytes, key strings, and byte patterns. Useful for endpoint detection alongside network rules.
SHIPPED v2.4
PCAP DIFF MODE
Compare two captures side-by-side, highlighting frames that differ between a baseline and a variant. Useful for validating that a rule change catches the new attack variant but not normal traffic.
SHIPPED v2.4
MITRE ATT&CK MAPPING
Tag each generated session with relevant ATT&CK technique IDs (e.g. T1071.001 for HTTP C2, T1558.003 for Kerberoasting). Displayed in the INFO tab and embedded in Sigma rule metadata.
SHIPPED v2.4
SESSION TEMPLATES
Save named multi-session configurations (e.g. "Ransomware Staging Chain", "APT Lateral Movement") as JSON presets and reload them in one click. Shareable via URL fragment encoding.
SHIPPED v2.4
PCAP ANNOTATION
Add Wireshark-compatible EPB comments to frames before download. Analysts receive the capture with contextual notes embedded — "credentials transmitted here", "NTLMSSP challenge for offline cracking", etc.
SHIPPED v2.4
EXPORT TO CSV / JSON
Export the packet summary as structured data for SIEM lab ingestion, spreadsheet analysis, or scripted processing without requiring Wireshark or tshark to be installed.
SHIPPED v2.4
PROTOCOL EXPLAINER PANEL
Collapsible sidebar explaining what each packet in the summary means from an analyst perspective — not just the wire format, but the security relevance: "this is where credentials are transmitted", "this is the challenge that would be captured for offline cracking".
SHIPPED v2.5
IPv6 SUPPORT
IPv6 headers, extension headers, ICMPv6, and DHCPv6. Many environments are dual-stack and detection rules often have IPv6 blind spots that synthetic captures could help test.
SHIPPED v2.4
PCAP-NG FORMAT
Output in the newer PCAP Next Generation format with interface description blocks, name resolution blocks, and per-packet comment annotations — required for some modern tooling.
SHIPPED v2.5
ADDITIONAL PROTOCOLS
NFS, Redis, PostgreSQL, MQTT, CoAP, RADIUS, BGP, OSPF, WebSocket, HTTP/2, gRPC, QUIC, EtherNet/IP, BACnet, DNSoverHTTPS variants, VXLAN, GRE tunnelling.
IDEA
COLLABORATIVE MODE
Real-time session sharing via WebRTC or a lightweight backend so a team can build and review the same multi-session capture simultaneously — useful for red/blue team exercises.
